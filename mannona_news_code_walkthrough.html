شرح كود شاشات Mannona-News سطر بسطر

دليل تحليلي شامل يغطي كود كل شاشة ومسار استرجاع بيانات الأخبار والطقس

شاشة الهيكل العام والتنقل (Home Shell Screen)

lib/features/home_screen/presentation/home_shell_screen.dart
final List<Widget> _screens = const [ ExploreScreen(), ..., WeatherScreen() ];
تعريف قائمة الشاشات الرئيسية الأربع للتطبيق المرتبطة بشريط التنقل السفلي.
IndexedStack(index: _currentIndex, children: _screens)
استخدام IndexedStack للحفاظ على حالة وتمرير كل شاشة في الذاكرة دون إعادة بنائها من الصفر عند التنقل.
CustomBottomNavBar(selectedIndex: _currentIndex, onItemTapped: (i) => setState(() => _currentIndex = i))
تحديث الصفحة النشطة عند الضغط على أي عنصر في شريط التنقل السفلي الحديث المخصص.

شاشة الاستكشاف والأخبار (Explore Screen)

lib/features/explore_screen/presentation/explore_screen.dart
final data = await _newsService.getEverything(query: query);
استدعاء خدمة NewsService عبر عميل Dio لإرسال طلب لنقطة /everything بالكلمة المفتاحية المختارة.
_heroArticle = data.first; _articles = data.sublist(1);
فصل أول خبر ليكون هو المقال البارز الكبير في أعلى الشاشة، وباقي الأخبار توضع في القائمة السفلية.
CategoryChip(label: cat, isSelected: _selectedCat == cat, onTap: ...)
شريط الفئات التفاعلي (Travel, Tech, Business, Science)؛ عند النقر على أي فئة يعاد جلب أخبارها فوراً.
Image.network(_heroArticle!.urlToImage!, errorBuilder: ...)
تحميل صورة المقال من السيرفر مع وضع بديل رمزي في حالة وجود رابط تالف أو انقطاع الاتصال.

شاشة نتائج البحث (Search Results Screen)

lib/features/explore_screen/presentation/search_results_screen.dart
void _performSearch(String query) async { ... }
دالة البحث الحية: تتأكد أن النص غير فارغ ثم تطلب الأخبار المطابقة للكلمة عبر NewsAPI.
_isLoading ? Center(child: CircularProgressIndicator()) : ...
إظهار مؤشر التحميل ريثما ينتهي السيرفر من معالجة الاستجابة، ثم عرض قائمة النتائج.
ExploreNewsItem(article: art, onTap: () => Navigator.push(...ArticleDetailScreen(...)))
عرض بطاقة الخبر الموحدة، وعند الضغط عليها يفتح التطبيق شاشة قراءة المقال بالتفصيل.

شاشة تفاصيل المقال (Article Detail Screen)

lib/features/article_screen/presentation/article_detail_screen.dart
final status = await BookmarkStorage.isBookmarked(widget.article.title);
فحص ما إذا كان المقال محفوظاً مسبقاً في الذاكرة لتحديد شكل ولون أيقونة المفضلة (مظللة أم فارغة).
await BookmarkStorage.toggleBookmark(widget.article);
حفظ أو إزالة المقال من قائمة الـ Bookmarks داخل SharedPreferences بنقرة واحدة.
Stack(children: [ Positioned(child: Image.network(...)), Positioned.fill(...) ])
تصميم حديث واحترافي يضع صورة المقال في الخلفية العلوية، مع لوحة بيضاء منحنية تحتوي على نصوص المقال قابلة للتمرير.

lib/features/bookmark_screen/presentation/bookmark_screen.dart
final data = await BookmarkStorage.getBookmarks();
تحميل المقالات التي قام المستخدم بحفظها مسبقاً من الذاكرة المحلية وعرضها مباشرة.
onLongPress: () => _showDeleteDialog(article)
الضغط المطول على أي مقال يفتح نافذة التأكيد المخصصة DeleteBookmarkDialog لحذفه من المفضلة.

شاشة الطقس والأحوال الجوية (Weather Screen)

lib/features/weather_screen/presentation/weather_screen.dart
final data = await _weatherService.getWeather(lat: 30.5877, lon: 31.4798);
استدعاء خدمة WeatherService عبر Dio لجلب بيانات طقس القاهرة الحية من OpenWeatherMap.
double tempC = rawTemp > 150 ? rawTemp - 273.15 : rawTemp;
التحويل الرياضي الذكي: تحويل درجات الحرارة من مقياس كلفن (Kelvin) الافتراضي في الـ API إلى درجات مئوية (Celsius).
WeatherInfoBox(icon: Icons.air, value: '${_weather!.windSpeed} mp/h', ...)
عرض عناصر شبكة المؤشرات الجوية (الرياح، الرطوبة، الضغط الجوي، والفهرنهايت) في صناديق منظمة تطابق التصميم.
